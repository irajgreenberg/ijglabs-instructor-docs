## “No cohort attached to this course (legacy data)”
Open the course detail page once. The cohort is lazy-created on first read. Return to the dashboard and try again.

## CSV import shows “0 valid emails”
Your file probably lacks an email column. The parser looks for a column whose values match `something@something.tld`. Open the file in a spreadsheet, confirm the email column has values, and re-export.

## Send invites button is disabled
There are no pending students. Everyone is already signed in, or you have not added students yet.

## A student cannot sign in
Make sure their email is in the cohort or whitelisted by an admin. Auth.js rejects sign-ins for un-whitelisted emails.

## Role change did not take effect
Auth.js stores the role in a JWT. The user must sign out and sign back in for the new role to apply.
