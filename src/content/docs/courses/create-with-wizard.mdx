---
title: Create with the wizard
description: Build a course, lessons, and empty cohort in four steps.
---

Open `/teacher`, click **Create course**, then work left to right through the Course Wizard.

1. **Config**: enter a required **Title**, optional **Description**, and a free-form **Section** such as `001`, `Fall 2026 §A`, or `MWF 10am`. Pick `p5.js`, `three.js`, or `GLSL`; this only affects code lessons. Set 1–30 lessons, pass threshold, and max time. Choose default media chips: image, video, 3D, code, or app. Leave empty when AI should choose per lesson. Use **Skip — create empty course** if you will author manually.
2. **Syllabus**: upload `.pdf`, `.docx`, `.md`, or `.txt` up to 15 MB, or paste text. Use **Brainstorm with AI** below the textarea to shape the plan. Click **Use as syllabus ↑** to summarize the chat into the syllabus box. If text already exists, confirm replacement.
3. **Review**: scan AI-proposed lessons. Inline-edit titles and descriptions, remove extras, set per-lesson media chips, or use the range helper to apply media types to lessons N–M.
4. **Create**: click once. Studio creates the course, lessons, and an empty cohort atomically.
