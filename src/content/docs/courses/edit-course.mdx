---
title: Edit a course
description: Update course details and lesson content after creation.
---

Course details live at `/teacher/courses`. From the Teacher Dashboard sidebar list, click a course.

1. In the header, click the title, section, or description value to edit it inline.
2. Use **Clone** to create another section, or **Archive** / **Delete** when a course should stop being used.
3. In the Lessons block, click **Add lesson** to create a new lesson.
4. Click the **pencil icon** beside a lesson to edit its title, framework, description, learning goals, opening prompt, tutor notes, and media type chips.
5. Click **Author with AI** to open `/teacher/courses/[id]/author`, a chat-only workspace for iterating on lessons with AI.
