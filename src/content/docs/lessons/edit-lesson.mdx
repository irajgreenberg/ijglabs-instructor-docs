---
title: Edit a lesson
description: Tune lesson instructions, goals, tutor notes, and media chips.
---

From a course detail page, click the **pencil icon** next to a lesson.

1. Edit **Title** and **Description** so students know the task.
2. Choose **Framework**: `p5.js`, `three.js`, or `GLSL` for code-focused lessons.
3. Enter **Learning goals**, one per line.
4. Write the **Opening prompt**. This is the first message students see when the lesson begins.
5. Add **Tutor notes**. Students do not see these; they guide the AI tutor.
6. Set **media type chips** to lock the lesson to image, video, 3D, code, app, or leave empty for unrestricted tools.

Course-level defaults include pass threshold, max time, scoring on/off, and token budget. If the UI does not expose those settings yet, Studio uses the defaults chosen during course creation.
