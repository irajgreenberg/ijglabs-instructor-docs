---
title: Publish
description: Choose enrollment mode, optional commons listing, and invite students.
---

Publishing makes a course joinable. It does not automatically send invite emails.

1. Open the course detail page and click **Publish**.
2. In the modal, choose a publish mode.
3. Choose **Enrollment mode** when only people in the cohort should join.
4. Choose **Open mode** when anyone with the invite code can join. Studio generates a six-character code and shows it on the course page.
5. In Open mode, optionally enable **List in Learning Commons**. This adds the course to `/commons` so other teachers can browse and clone it.
6. Confirm publish.
7. Return to the cohort panel and send invites to pending students.

> If something goes wrong: for controlled sections, use Enrollment mode and add students to the cohort instead of sharing an Open invite code.
